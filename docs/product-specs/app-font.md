# App font

On tvOS, **Settings → Customize → App Font** lets the user choose **System**,
**Rounded**, or **Serif** for Screen's app UI. System is the default. The selection
applies immediately and persists across relaunches and Jellyfin user switches.

The choice changes the system font design while preserving the app's text hierarchy,
semantic weights, and accessibility sizing where those styles are used. It applies to
Screen's UI only; it does not change subtitle configuration or subtitle rendering.
The iOS app keeps its existing typography.
